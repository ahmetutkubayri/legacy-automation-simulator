# Legacy Automation Simulator

An independently developed portfolio project demonstrating enterprise workflow
automation, configurable data validation, entity matching, record
reconciliation, exception reporting, and resilient integration with a
simulated legacy system — using entirely synthetic data. The legacy system is
simulated in-process, complete with configurable faults (busy timeouts, flaky
controls, stalled pagination), so the automation's resilience is reproducible
and fully tested. Full documentation, architecture diagrams, and a one-command
demo will land as the implementation roadmap completes.

> Status: under active development. Not yet released.
